# Frifor Growth Audit

**Live → https://eddieatadapty.github.io/frifor-flow-rebuild/**

Five ideas to turn more Frifor users into subscribers, each built into a clickable version of Frifor's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the answers you collect | +10–20% CR to purchase |
| 02 | Let the compass work once before the price | +10–15% CR to purchase |
| 03 | Answer ✕ with a different offer, and test three | +10–15% ARPU |
| 04 | Make the annual saving impossible to miss | +10–15% ARPU · annual share |
| 05 | Proof where decisions happen | +5–15% CR to purchase |

Every price, rating and feature comes from Frifor's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Frifor. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
